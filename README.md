## About

I build the parts of a system that move money and stock: payments, wallets, accounting and inventory, exposed as tested REST APIs. Two years of production Laravel across fintech, ERP, e-commerce and healthcare.

Most of my work is for clients and employers, so it lives in private repositories. The contribution graph below includes that private activity (commit counts only, no code or repository names).

## What I work on

- **Payments:** Paymob (cards, Apple Pay, STC Pay), Geidea, Fawaterk, Kashier, MyFatoorah and PayPal, with signed-webhook verification and status reconciliation
- **ERP and accounting:** double-entry GL posting, multi-branch inventory, multi-currency invoicing
- **Real-time:** Laravel Reverb, Pusher, WebSockets and FCM
- **Multi-tenant SaaS:** database-per-tenant isolation, automated provisioning, tenant-aware queues
- **Architecture and quality:** Domain-Driven Design, DTOs, service and repository patterns, PHPUnit and Pest
